# 3DLS 3D Printer
This repository contains the design files and STLs for the 3DLS 3D Printer.
The current build uses X and Y MGN12 rails (located in the `Rails` folder).

## Folder Structure
- **Rails/** - Current build files using X and Y MGN12 rails.
- **CAD_Files/** - Original or alternative SolidWorks CAD files (`.SLDPRT`, `.SLDASM`, `.STEP`).
- **STLs/** - Printable parts.
- **Images/** - Photos and renderings of the build.
- **Archives/** - Zipped archives of legacy components.
- **X Axis Screw / Y Axis Screw** - Legacy screw-driven axis designs.
- **Improved Parts** - Iterations on various parts.
